## 1. วัตถุประสงค์ของระบบ
ใช้สำหรับตรวจสอบสถานะความพร้อมของห้องเรียน ห้องปฏิบัติการคอมพิวเตอร์ และห้องประชุมทั้งหมด **22 ห้อง** ของคณะวิทยาการจัดการแบบเรียลไทม์ (Real-time) โดยระบบจะคำนวณสถานะห้องอัตโนมัติตามวันและเวลาปัจจุบันควบคู่กับตารางสอนประจำภาคการศึกษาและการจองห้อง

## 3. ขั้นตอนการใช้งานสำหรับผู้ใช้งานทั่วไป (User)

### 3.1 การดูภาพรวมบนหน้าแดชบอร์ด (เมนู `แดชบอร์ด`)
1. เมื่อเข้าสู่หน้าเว็บไซต์ ระบบจะแสดงหน้า **แดชบอร์ดภาพรวม** เป็นหน้าแรก
2. **การ์ดสรุปสถานะ 4 หมวด**:
   - **ห้องว่าง (พร้อมใช้)**: จำนวนห้องที่ว่างในขณะนั้นและสามารถกดจองได้ทันที
   - **กำลังเรียนการสอน**: จำนวนห้องที่มีอาจารย์และนักศึกษาเรียนอยู่ตามตารางสอน
   - **มีการจองล่วงหน้า**: จำนวนห้องที่มีการจองสำหรับกิจกรรม สัมมนา หรือสอบ
   - **ปิดปรับปรุง / ซ่อม**: จำนวนห้องที่อยู่ระหว่างการซ่อมบำรุง
3. **การจำลองดูสถานะห้องตามช่วงเวลา (ลองดูสถานะ)**:
   - สามารถกดปุ่มช่วงเวลาจำลอง เช่น `จันทร์ 09:00`, `จันทร์ พักเที่ยง`, `อังคาร 14:00`, `พุธ 10:00` เพื่อตรวจสอบสถานะห้องในช่วงเวลาต่างๆ และกดปุ่ม `เวลาจริง` เพื่อกลับสู่เวลาปัจจุบัน
4. **ส่วนชั้นเรียนและกิจกรรมที่กำลังใช้งานขณะนี้ (Active Now)**:
   - แสดงรายการห้องที่กำลังมีการเรียนการสอนอยู่ในเวลานั้น
   - คลิกปุ่ม **`ห้องว่างวันนี้`** เพื่อดูรายชื่อห้องที่ว่างในวันปัจจุบันทันที

### 3.2 การค้นหาและกรองรายการห้องเรียน (เมนู `รายการห้องเรียน`)
1. คลิกไอคอน **รายการห้องเรียน** (รูปประตู 🚪) บนแถบเมนูด้านบน
2. **กรองตามหมวดหมู่ห้อง**: เลือกคลิก `ทั้งหมด`, `📖 ห้องเรียน`, `💻 แล็บคอม`, หรือ `🏛️ ห้องประชุม`
3. **ค้นหาห้องว่างตามวันที่**: คลิกช่องปฏิทินด้านซ้ายเพื่อเลือกวันที่ต้องการใช้งาน ระบบจะคำนวณสถานะว่าง/ไม่ว่างของทุกห้องในวันที่เลือกทันที
4. **ค้นหาด้วยคำสำคัญ**: พิมพ์ชื่อห้อง รหัสห้อง หรือชื่ออุปกรณ์ (เช่น `Projector`, `Smart TV`, `ไมค์`, `RTX`)
5. **กรองตามสถานะและชั้น**: เลือกดรอปดาวน์สถานะห้อง (`ห้องว่าง`, `กำลังใช้งาน`, `มีการจอง`, `ปิดปรับปรุง`) หรือเลือกตามชั้น (`ชั้น 3`, `ชั้น 4`)

### 3.3 การดูรายละเอียดและสเปกอุปกรณ์ประจำห้อง
- คลิกที่การ์ดห้องเรียน หรือกดปุ่ม **`รายละเอียด`** บนการ์ดห้อง
- หน้าต่างรายละเอียดจะแสดง **ความจุที่นั่ง**, **รายการอุปกรณ์โสตทัศนูปกรณ์**, **สเปกคอมพิวเตอร์และซอฟต์แวร์ (สำหรับห้องแล็บ)** รวมถึง **ตารางเรียนประจำห้องนั้น**

## 4. ความหมายของป้ายสถานะห้อง (Status Badges)

| ป้ายสถานะ | สีสัญลักษณ์ | ความหมายและการดำเนินการ |
| :--- | :---: | :--- |
| **ว่าง (Available)** | 🟢 สีเขียว | ห้องว่างในขณะนั้น ผู้ใช้สามารถกดปุ่ม **`จองห้อง`** เพื่อขอเข้าใช้งานได้ทันที |
| **กำลังเรียน/ใช้งาน (Occupied)** | 🟡 สีเหลือง/ส้ม | มีรายวิชาตามตารางสอนหรือกิจกรรมกำลังใช้งานอยู่ในช่วงเวลานั้น |
| **มีการจอง (Reserved)** | 🌸 สีชมพู | ห้องได้รับการอนุมัติจองล่วงหน้าสำหรับกิจกรรม/สัมมนา/สอบในวันดังกล่าว |
| **ปิดปรับปรุง (Maintenance)** | 🔴 สีแดง | ห้องหรืออุปกรณ์หลักอยู่ระหว่างการซ่อมบำรุง งดเปิดให้จองชั่วคราว |
