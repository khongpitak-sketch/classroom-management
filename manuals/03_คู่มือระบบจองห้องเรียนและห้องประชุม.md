# 📘 คู่มือการใช้งานระบบที่ 3: ระบบจองห้องเรียน ห้องปฏิบัติการ และห้องประชุมออนไลน์
**สำหรับผู้ใช้งานทั่วไป (User Manual)**  
**คณะวิทยาการจัดการ มหาวิทยาลัยนราธิวาสราชนครินทร์**

---

## 1. วัตถุประสงค์ของระบบ
ให้บริการยื่นคำขอจองห้องเรียน (สำหรับการเรียนการสอนชดเชย กิจกรรม หรือการสอบ) ห้องปฏิบัติการคอมพิวเตอร์ และห้องประชุมสัมมนาแบบออนไลน์ โดยระบบจะตรวจสอบเวลาชนกับตารางสอนปกติและการจองอื่นให้อัตโนมัติ (Conflict Detection) พร้อมบันทึกข้อมูลลงฐานข้อมูล Cloud แบบเรียลไทม์

---

## 2. ขั้นตอนการยื่นคำขอจองห้องเรียน / ห้องประชุม

### ขั้นตอนที่ 1: เปิดแบบฟอร์มการจองห้อง
ผู้ใช้งานสามารถเปิดแบบฟอร์มจองห้องได้ 3 จุด ดังนี้:
1. คลิกปุ่ม **`+ จองห้อง`** (สีน้ำเงิน) ที่มุมขวาบนสุดของหน้าจอ
2. คลิกปุ่ม **`จองห้อง`** บนการ์ดห้องเรียนที่สถานะว่างในหน้ารายการห้องเรียน
3. คลิกปุ่ม **`+ จองห้องเรียน / ห้องประชุม`** ในเมนู **การจองห้อง**

### ขั้นตอนที่ 2: กรอกรายละเอียดในฟอร์มจองห้อง
1. **เลือกห้องเรียนที่ต้องการจอง** *(จำเป็น)*: เลือกห้องเรียน ห้องแล็บคอม หรือห้องประชุมจากรายการ
2. **วันที่ใช้งาน** *(จำเป็น)*: เลือกวันที่ต้องการเข้าใช้ห้องจากปฏิทิน
3. **เวลาเริ่ม – เวลาสิ้นสุด** *(จำเป็น)*: เลือกเวลาเริ่มต้น (เช่น `09:00 น.`) และเวลาสิ้นสุด (เช่น `12:00 น.`)
4. **ชื่อวิชา / หัวข้อกิจกรรม** *(จำเป็น)*: ระบุชื่อรายวิชา หรือชื่อการประชุม/โครงการ
5. **ชื่อผู้ขอจอง / ผู้สอน** *(จำเป็น)*: ระบุชื่อ-นามสกุลของอาจารย์ บุคลากร หรือนักศึกษาผู้ขอจอง
6. **เบอร์โทรศัพท์ติดต่อ** *(จำเป็น)*: ระบุเบอร์โทรศัพท์ที่สามารถติดต่อได้สะดวก
7. **สาขาวิชา / หน่วยงาน**: ระบุชื่อสาขาวิชาหรือหน่วยงานสังกัด
8. **วัตถุประสงค์การใช้ห้อง / หมายเหตุ**: ระบุรายละเอียดเพิ่มเติม เช่น จำนวนผู้เข้าร่วม หรืออุปกรณ์ที่ต้องการใช้เป็นพิเศษ

### ขั้นตอนที่ 3: ยืนยันการจองและตรวจสอบเวลาชนอัตโนมัติ
1. คลิกปุ่ม **`ยืนยันการจองห้อง`**
2. ระบบจะตรวจสอบอัตโนมัติว่าห้องและช่วงเวลาที่เลือกชนกับตารางเรียนปกติหรือการจองของผู้อื่นหรือไม่:
   - **กรณีเวลาชน**: ระบบจะแสดงข้อความแจ้งเตือนทันที ให้ผู้ใช้งานเลือกช่วงเวลาใหม่หรือเปลี่ยนห้องเรียน
   - **กรณีห้องว่าง**: ระบบจะบันทึกคำขอจองเข้าสู่ระบบทันทีในสถานะ **🟡 รออนุมัติ (Pending)**

## 3. การติดตามสถานะการจองและการส่งออกข้อมูล
1. คลิกเมนู **`การจองห้อง`** (ไอคอนรูปปฏิทินเครื่องหมายถูก 📅) บนแถบเมนูด้านบน
2. **การกรองดูรายการจอง**:
   - **`ทั้งหมด`**: แสดงรายการจองทั้งหมดในระบบ
   - **`🟢 อนุมัติแล้ว`**: รายการที่ผู้ดูแลระบบ (Admin) อนุมัติให้เข้าใช้ห้องได้แล้ว
   - **`🟡 รออนุมัติ`**: รายการคำขอใหม่ที่อยู่ระหว่างรอผู้ดูแลระบบตรวจสอบ
   - **`🏁 สิ้นสุดการจอง`**: รายการจองที่ผ่านช่วงเวลาใช้งานเสร็จสิ้นแล้ว
3. **การเรียงลำดับข้อมูล**: สามารถคลิกที่หัวตาราง (`รหัสการจอง`, `ห้องเรียน`, `วันที่ & เวลา`, `วิชา / กิจกรรม`, `ผู้ขอจอง`, `สถานะ`) เพื่อเรียงลำดับข้อมูลจากน้อยไปมากหรือมากไปน้อย
4. **การส่งออกข้อมูล**: คลิกปุ่ม **`ส่งออก CSV`** เพื่อดาวน์โหลดตารางรายการจองไปเปิดในโปรแกรม Microsoft Excel
