**สำหรับผู้ใช้งานทั่วไป (User Manual)**

## 1. วัตถุประสงค์ของระบบ
ใช้สำหรับแจ้งปัญหาอุปกรณ์โสตทัศนูปกรณ์ เครื่องคอมพิวเตอร์ เครื่องปรับอากาศ ระบบเครือข่าย หรือครุภัณฑ์ภายในห้องเรียนชำรุดเสียหาย เพื่อให้เจ้าหน้าที่ฝ่ายอาคารสถานที่และนักวิชาการคอมพิวเตอร์เข้าดำเนินการตรวจสอบและซ่อมบำรุงได้อย่างรวดเร็ว

---

## 2. หมวดหมู่อุปกรณ์ที่รองรับการแจ้งซ่อม (9 หมวดหมู่)

| ลำดับ | หมวดหมู่อุปกรณ์ | ตัวอย่างปัญหาที่พบบ่อยในระบบ |
| :---: | :--- | :--- |
| **1** | 📽️ **โปรเจกเตอร์** | เปิดไม่ติด, ภาพมัว/หลอดเสื่อม, สาย HDMI/VGA ชำรุด, จอรับภาพไม่เลื่อน |
| **2** | ❄️ **เครื่องปรับอากาศ** | แอร์ไม่เย็น/มีแต่ลม, น้ำแอร์หยด/รั่ว, แอร์มีเสียงดัง, รีโมทแอร์เสีย |
| **3** | 🖥️ **คอมพิวเตอร์ / PC** | เครื่องเปิดไม่ติด, จอภาพไม่แสดงผล, เครื่องค้าง/จอฟ้า, โปรแกรมใช้งานไม่ได้ |
| **4** | 🖱️ **เมาส์ / คีย์บอร์ด** | เมาส์คลิกไม่ติด/เลื่อนไม่ได้, คีย์บอร์ดปุ่มค้าง/พิมพ์ไม่ติด, พอร์ต USB เสีย |
| **5** | 🔊 **ระบบเสียง / ไมค์** | ไมโครโฟนไม่มีเสียง, ลำโพงเสียงซ่า/หอน, ถ่านไมค์ลอยหมด, เครื่องขยายเสียงไม่ติด |
| **6** | 🌐 **อินเทอร์เน็ต / LAN** | เชื่อมต่ออินเทอร์เน็ตไม่ได้, สาย LAN หัวหลวม/ชำรุด, สัญญาณ Wi-Fi อ่อน |
| **7** | 🔌 **ปลั๊กไฟ / ไฟฟ้า** | เต้ารับไฟไม่มีไฟ, หลอดไฟส่องสว่างดับ/กะพริบ, เบรกเกอร์ตัด |
| **8** | 🪑 **โต๊ะ / เก้าอี้** | เก้าอี้ชำรุด/ล้อหลุด, โต๊ะเรียนโยก/ขาหัก, กระดานไวท์บอร์ดชำรุด |
| **9** | ❓ **ปัญหาอื่นๆ** | ปัญหาความสะอาด กลอนประตู หน้าต่าง หรืออุปกรณ์อื่นๆ ภายในห้อง |

## 3. ขั้นตอนการแจ้งซ่อมอุปกรณ์สำหรับ User

1. **เข้าสู่ระบบแจ้งซ่อม**:
   - คลิกเมนู **`แจ้งซ่อมอุปกรณ์`** (ไอคอนรูปประแจ 🔧) บนแถบเมนูด้านบน แล้วคลิกปุ่ม **`+ แจ้งปัญหาอุปกรณ์ใหม่`**
   - หรือคลิกปุ่มไอคอนประแจ (`แจ้งซ่อม`) บนการ์ดห้องเรียนที่มีปัญหาโดยตรง
2. **ระบุข้อมูลในแบบฟอร์มแจ้งซ่อม**:
   - **เลือกห้องที่มีปัญหา** *(จำเป็น)*: เลือกห้องที่พบอุปกรณ์ชำรุด
   - **เลือกหมวดหมู่อุปกรณ์ที่ชำรุด** *(จำเป็น)*: คลิกปุ่มไอคอนหมวดหมู่ 1 ใน 9 หมวด
   - **เลือกจาก "ปัญหาที่พบบ่อย"**: คลิกที่ป้ายข้อความอาการเสียที่พบบ่อยเพื่อให้ระบบเติมหัวข้อปัญหาให้อัตโนมัติ หรือพิมพ์ระบุเองในช่อง **หัวข้อปัญหา / อุปกรณ์ที่ชำรุด**
   - **รายละเอียดอาการเสีย**: อธิบายรายละเอียดเพิ่มเติม เช่น หมายเลขเครื่องคอมพิวเตอร์ที่เสีย หรือตำแหน่งของแอร์ตัวที่มีปัญหา
   - **แนบรูปภาพหรือไฟล์หลักฐาน** *(ไม่บังคับ)*: คลิกในกรอบอัปโหลดเพื่อถ่ายภาพอาการเสียจากโทรศัพท์มือถือ หรือเลือกไฟล์รูปภาพ (`PNG`, `JPG`, `WEBP`) หรือ `PDF` (ขนาดสูงสุดไม่เกิน 10 MB)
   - **ระดับความด่วน** *(จำเป็น)*: เลือก `ทั่วไป`, `ปานกลาง`, หรือ `ด่วนมาก`
   - **ชื่อผู้แจ้ง** *(จำเป็น)*: ระบุชื่ออาจารย์ เจ้าหน้าที่ หรือนักศึกษาผู้แจ้ง
   - **ตัวเลือกปิดปรับปรุง**: หากปัญหาส่งผลให้ไม่สามารถใช้ห้องเรียนได้ชั่วคราว สามารถติ๊กถูกที่ช่อง *"ปรับสถานะห้องเป็น ปิดปรับปรุง (Maintenance) ทันที"*
3. **กดปุ่ม `ส่งข้อมูลแจ้งซ่อม`** เพื่อบันทึกรายการเข้าสู่ระบบ

## 4. การติดตามสถานะการซ่อมบำรุง
- ผู้ใช้งานสามารถดูรายการแจ้งซ่อมทั้งหมดได้ในตารางหน้า **`แจ้งซ่อมอุปกรณ์`**
- สามารถกรองดูตามสถานะ **`ทั้งหมด`**, **`รอดำเนินการ`**, หรือ **`✓ ซ่อมเสร็จสิ้น`** และกรองแยกตามหมวดหมู่อุปกรณ์ทั้ง 9 หมวดได้
- คลิกปุ่ม **`ดูรูปภาพ/หลักฐาน`** เพื่อเปิดดูภาพถ่ายอาการเสียที่ได้แนบไว้
- เมื่อเจ้าหน้าที่ดำเนินการซ่อมเสร็จสิ้นและอัปเดตสถานะเป็น **`ซ่อมเสร็จสิ้น`** ห้องเรียนที่ถูกตั้งเป็นปิดปรับปรุงจะถูกเปลี่ยนกลับเป็นสถานะ **`ว่าง (พร้อมใช้งาน)`** โดยอัตโนมัติ
